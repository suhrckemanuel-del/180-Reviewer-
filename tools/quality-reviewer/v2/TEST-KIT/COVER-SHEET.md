# The AI Quality Reviewer -- start here

Release **0000-TESTKIT/TESTKIT-00**. One page. Read it before you paste anything.

## 1. What to do

Paste **REVIEWER-SETUP.txt** into a new chat as one message. Then fill **TEAM-INPUT-TEMPLATE.txt**
and attach your selected original deliverable through an authorized route.
Then read the complete review. A pre-review read is optional and only needed when someone
is measuring learning.

## 2. Check the first line of what comes back

**The first line of your review must read exactly `KEYS: 0000-TESTKIT/TESTKIT-00`.
Anything else means part of the setup did not arrive: start a new chat and paste it
again.**

It is a one-paste fix, not a broken tool. Chat windows silently drop part of a long paste
when they run out of room, and nothing announces it. This line is how you see it.

## 3. Where to get a fresh copy

https://github.com/suhrckemanuel-del/180-Reviewer- (local candidate; consultant access not yet verified)

## 4. What this does not do

It does not approve anything and it does not give you a grade. There is no score, no
readiness level and no overall verdict, on purpose: the same deliverable was given two
different verdicts on identical input, so that half is not produced at all. You get the
findings, each one quoted from your own work, and you make the call.

A named human signs off on client work. That does not move.
