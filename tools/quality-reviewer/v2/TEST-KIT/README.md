# Generated candidate test kit

Read [Start here](START-HERE.md). Choose STUDENT-SETUP.txt plus STUDENT-INPUT-TEMPLATE.txt,
or LEAD-SETUP.txt plus LEAD-INPUT-TEMPLATE.txt. Optional HTML uses separate student/lead
templates and a shared deterministic renderer.

These files use test keys, not a registered release pair. Regenerate with
node tools/quality-reviewer/v2/build-bundle.js --sync-test-kit; check with --check.
Do not hand-edit generated files. Versioned supervised candidates live in ../releases/.

PASTE-*, REVIEWER-SETUP.txt, TEAM-INPUT-TEMPLATE.txt and COVER-SHEET.md retain the
older combined/internal validation path for recovery. They are not split-product starting
files. New candidate packages exclude that combined path. Current split files are generated
from the same underlying methodology rather than maintained separately.

Genuine sources, reviews, exports, screenshots and notes stay ignored under _client-private.
Owner approval of this split, intended account access and supervised acceptance remain open.
