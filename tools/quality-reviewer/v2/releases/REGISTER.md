# Release register

**This file is the authority on what a key means, not the date inside the key.** A review
arrives stamped with a key pair on its first line; look it up here. Comparisons are always
within a key, never across: a record stamped with a retired key is evidence about the
version that produced it and about no other.

Rows are appended by `build-bundle.js --release` and are never edited or deleted. A key
that is not in this table means a hand-edited bundle or a mistyped key: quarantine the
record, do not pool it.
